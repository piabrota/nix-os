# Start here: maker

Read these before you build:

1. The norms in the `AGENTS.md` of your working folder: the box's, then reels-fabric's.

Then wait for the task from the director or the operator: a slug. Do not start from this text alone.
Your first command is `reel render <slug>`: it checks the approval. While it runs, do nothing else.
Afterwards read `direction/shotlist.json` and `reel screenplay-view <slug>` to check each beat.

## Limits

- Two seats run at the same time at most. A render takes minutes: wait for it, do not start a second.
- You write only `build/`, `<out>/` (through `reel`) and `review/build.md`. No network, no download.
