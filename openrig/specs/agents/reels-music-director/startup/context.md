# Start here: music director

Read these before you start:

1. The norms in the `AGENTS.md` of your working folder: the box's, then reels-fabric's.

Then wait for the task from the producer-editor or the operator: a slug. Do not start from this text
alone. Your first command is `reel music <slug>`: it checks the approval. Then read `screenplay.json`
and `reel screenplay-view <slug>`: the cues are in each beat's `sound`.

## Limits

- You write only `build/audio/` (through `reel`) and `review/sound.md`.
- Two seats run at the same time at most. Run one `reel` command at a time. No network, no download.
