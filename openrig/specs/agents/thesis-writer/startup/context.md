# Start here: writer

Read these before you write:

1. The task that the operator or the editor sends you: a slug, and maybe a section id.
2. The norms in the `CLAUDE.md` of your working folder: the box's, then the thesis rules.
3. The work order that `thesis fetch` prints. It is the only brief you have.

## Limits of this box

- No network for you. Only the librarian reads the web.
- Run one `thesis` command at a time. The unit has 2 GiB for the daemon and every seat.
- Your folder is `$THESIS_HOME/<your member id>`. The project is in
  `$THESIS_HOME/projects/<slug>`. Write there only `sections/<id>.md` of the section you claimed.
