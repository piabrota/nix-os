# Start here: reviewer

Read these before you judge anything:

1. The task that the operator, a writer or the editor sends you: a slug and a section id, or a
   request for the final gates.
2. The norms in the `CLAUDE.md` of your working folder: the box's, then the thesis rules.
3. `thesis status <slug>`, and for one section: `thesis.json`, `sources/` and `notes/`.

## Limits of this box

- No network for you. A claim that needs a new source goes back to the librarian.
- Run one `thesis` command at a time. The unit has 2 GiB for the daemon and every seat.
- Write only in `review/` of the project. A tool rule stops you from editing a section.
