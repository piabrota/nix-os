# Start here: editor

Read these before you change anything:

1. The task that the operator sends you: the owner's brief, or a slug and a phase.
2. The norms in the `CLAUDE.md` of your working folder: the box's, then the thesis rules.
3. `thesis status <slug>`, if the project exists.

## Limits of this box

- No network for you. The librarian reads the web.
- Run one `thesis` command at a time, and never `assemble` while another seat builds.
- You can edit `thesis.json`, `notes/` and `data/`. A tool rule stops you from editing a section.
- You never start a seat. Say to the operator which seat to start next.
