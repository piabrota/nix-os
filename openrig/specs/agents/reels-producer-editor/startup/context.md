# Start here: producer and editor

Read these before you start:

1. The norms in the `AGENTS.md` of your working folder: the box's, then reels-fabric's.
2. `reel help`, for the commands of the table read.

Then wait for the task from the creative director or the operator: a slug. Do not start from this
text alone. Your first command is `reel lint <slug>`; the first stage after it is `reel approve`.

## Limits

- Approve only after a pass, never to save time: the approval hash is the gate of every stage.
- Two seats run at the same time at most. A render takes minutes: wait for it, do not start another.
- You write only `review/`, `build/` and `<out>/` (through `reel`). No network, no download.
