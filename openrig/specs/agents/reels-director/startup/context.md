# Start here: director

Read these before you direct:

1. The norms in the `AGENTS.md` of your working folder: the box's, then reels-fabric's.

Then wait for the task from the script editor or the operator: a slug. Do not start from this text
alone. Your first command is `reel shotlist <slug>`: it checks the approval. Then read
`screenplay.json` and `reel screenplay-view <slug>`: they are the brief of every shot.

## Limits

- You write only `direction/`. `reel` refuses to run when `screenplay.approved` does not match the
  screenplay: stop and tell the operator.
- No network, no stock image, no downloaded font or file.
