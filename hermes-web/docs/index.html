The rule

nix-os, main

Nix owns the config. Change it in a pull request, not in this dashboard. A human merges the pull request, and the merge deploys it.

How a deploy works ↗

This box

hosts/piabrota2

  • hermes-agent

    The full Hermes: its chats, its cron jobs and omp, the coding worker. The unit has a limit of 8G of memory.

    docs/HERMES.md

  • hermes-backend

    This dashboard. It listens on 127.0.0.1 only, behind nginx and basic auth. It has its own limit of 2G.

    docs/HERMES.md

  • openrig

    The engine of the software factory: builder and reviewer seats that run omp. Hermes routes. A human merges.

    rig.piabrota.art · same login

  • piabrota-hermes[bot]

    The GitHub App of Hermes. It pushes to hermes/* branches and opens pull requests. It never merges.

    docs/HERMES.md
